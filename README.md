# ThermalQuasi-incompressibleMSNS

This repository contains the implementations of the numerical schemes developed in [XX].

The repository provides implementations in **NGSolve** and **Firedrake** for the numerical experiments presented in the paper.

- **NGSolve:** Implementation of the semi-implicit Euler scheme and the CPG scheme (lowest-order version only). These implementations are used to obtain the convergence results, test the structure-preserving properties of the schemes, and simulate the applied example.
- **Firedrake:** Implementation of the CPG scheme for the applied example. Unlike the NGSolve implementation, the Firedrake implementation supports arbitrary polynomial orders in time.

## Repository structure

### NGSolve

**Required version:** NGSolve 6.2.2505

Install NGSolve using pip:

```bash
pip install --upgrade ngsolve
```

#### Simulation scripts

- `Euler_structure.py`, `Euler_looped.py`, `Euler_applied.py`

  Implementations of the semi-implicit Euler scheme for the structure-preserving test (Fig xx), the convergence study (Table xx), and the applied example (Fig xx), respectively.

- `CPG_structure.py`, `CPG_looped.py`

  Implementations of the CPG scheme for the structure-preserving test (Fig xx) and the convergence study (Table xx), respectively. The implementation is restricted to the lowest polynomial order.

#### Postprocessing

- `Compute_Rates_Euler.py`, `Compute_Rates_CPG.py`

  Postprocessing scripts that compute the errors and convergence rates from the output generated by `Euler_looped.py` and `CPG_looped.py`, respectively.
