# ThermalQuasi-incompressibleMSNS

This repository contains the implementation of the numerical schemes developed in xx.

The repository includes an NGSolve implementation of the semi-implicit Euler scheme, as well as the CPG (lowest order only).
They are used to generate convergence results and the structure-preserving property test, as well as an implementation of the applied example.

Furthermore, it contains the Firedrake implementation of the CPG scheme for the applied example. Note that the Firedrake version allows the arbitrary-order implementation of the CPG.
